คลิก ✏️ เพื่อเปลี่ยนชื่อคอลัมน์ (กรณีชื่อในไฟล์ไม่ตรงหรืออ่านยาก) • สูตรใช้รหัส C1, C2, … อ้างอิงคอลัมน์ รองรับ + − × ÷ วงเล็บ และตัวเลข เช่น (C3+C4)/2, C8*4.187*C9/3.5169 • คอลัมน์ที่สร้างใช้ map เข้า parameter, summary และกราฟได้เหมือนคอลัมน์ปกติ

🗂️ Standard Parameters — จับคู่คอลัมน์ข้อมูลดิบ

kW, RT, kW/RT, % เหมือนกันทั้งสองระบบ — ระบบจะแปลงอุณหภูมิ/อัตราการไหลให้อัตโนมัติ kW > kW ถึงนับว่ารัน (คอลัมน์ Status 0/1 ใช้ >0.5 อัตโนมัติ)

🟢 mapped = พบคอลัมน์ในไฟล์ • 🔵 คำนวณ = คำนวณจาก parameter อื่น (เช่น DT = Return − Supply, RT จาก Flow×DT, Eff = kW/RT, Total kW = Σ kW ทุกตัว, WB = คำนวณจาก DB + RH ด้วยสมการไซโครเมตริก, Chiller Run = นับเครื่องที่ kW > 5 kW จากคอลัมน์ kW รายตัว หรือจากคอลัมน์ status 0/1) • เลือกได้หลายคอลัมน์ต่อ 1 parameter เช่น Chiller (kW) = CH-1 + CH-2 + CH-3 → kW/Flow/RT จะรวมกัน (Σ) ส่วนอุณหภูมิ/DT/% จะเฉลี่ยให้ • ติ๊ก ✓ เพื่อรวมใน summary
